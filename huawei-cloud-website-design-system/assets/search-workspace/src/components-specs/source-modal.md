# SourceModal — complex source pilot

Baseline: PortalUI3.0.17 modal.md and unchanged public CSS. Source classes: por-modal/show, por-modal-backdrop/show, por-modal-dialog-{small,middle,large,xlarge}, inner/head/title/body/text/footer. Source desktop widths400/550/700/900; source mobile345. Geometry caps to the confirmed viewport margins24 (<=375:14). Existing source skin owns appearance; composed SourceButton/SearchInput public entries keep their own styles/states.

Controlled API: open, onOpenChange, title, children, size (defaultsmall), closeLabel and optional footer. ReactNode replaces source JQuery/HTMLElement/HTML-string injection; raw HTML is not accepted. One active modal at a time; no stacked-dialog support claimed. Role dialog, aria-modal, useId title/body descriptions. Portal host lives under body, sets other body children inert and source por-modal-open scroll lock. Initial focus first enabled element; Tab wraps, Escape/backdrop/footer close, restore prior inert/class/focus on close/unmount. A missing trigger cannot receive restored focus; only restore connected nodes.

States: closed has no overlay DOM; open renders source show classes. Default footer uses SourceButton; custom footer must provide a named close action. Size matrix is four stories, title/content supplied by caller; empty content remains an explicit caller responsibility. Background click is close; clicks inside do not close. Dark/global localization depend on provided approved resources, not inferred source color changes. The reduced-motion media query disables the overlay transition; this does not establish complete motion/accessibility acceptance.

Acceptance: Storybook play must exercise actual open, initial focus, focus containment, Escape and restore; public import must be visible. Source CSS/size reference and user-approved grid differ only by documented max-width cap. Formal same-source visual comparison and manual screen-reader checks are separate; passing play is not full-family certification.

Long content: overlay scrolls vertically with overscroll containment; title/body break otherwise unbreakable strings. These are explicit layout adaptations; they do not replace source colors or dependency button/input styles. Validate narrow and landscape viewports before family completion.


2.4 completes source status icon axis(prompt/success/warn/error), native named corner close and backdropClose(true default). Decorative status icon must not be the only carrier of meaning; caller title/body describe the outcome. Default footer maps source default32px button; custom footer composes public dependencies and must retain a close action. Source JQuery show/hide/reset map to controlled open/title/children/size/React footer props; no raw HTML strings or JQuery-specific animation callback compatibility is claimed. Corner button font/background/border reset preserves source layout with a visible keyboard focus repair. Source embedded glyph fonts are bundled. One active modal is the supported scope. The nested autocomplete story tests first-Escape-popup, second-Escape-modal, restoration and dialog ARIA. Source/live pixel calibration and manual screen reader remain independent pending checks.
