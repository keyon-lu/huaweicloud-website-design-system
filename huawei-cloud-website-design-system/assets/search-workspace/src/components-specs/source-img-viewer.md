# 图片查看器

基准为PortalUI3.0.17 img-viewer文档，新增PIX-0047:41717文档图片的明确要求：7:41732图片描边1px #ebebeb，7:41816悬浮系统放大指针、点击放大。SourceImageViewer/PortalImageViewer通过登记素材assetId传入原始图片，不重新画图片。API需要alt、打开和关闭的可访问名称。

预览是可键盘激活的button，hover使用系统zoom-in指针。原生dialog提供模态语义、焦点约束和Escape关闭；关闭回到触发按钮。弹层使用现有por-modal内层和现有PortalUI secondary按钮皮肤，视口宽度/高度上限属于有记录的工程适配，并非源稿固定尺寸。图片按原始比例contain，内容不裁切。此轮仅实现img/登记素材路径；文档允许的背景DOM模式、完整源视觉与人工读屏验收仍待完成。不把本组件等同于架构图等其它楼层。

## 2026-10-21移除推荐
用户明确要求去掉此基础组件。旧实现仅为兼容归档保留，禁止在新规范页面中生成，不把导航Logo样本当作图片查看器设计。
