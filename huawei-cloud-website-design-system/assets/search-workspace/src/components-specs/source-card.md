title/description必填，支持center/left、明确headingLevel2～6；不会用文本长度猜测层级或裁掉正文。没有href时为article；有href时整个卡片使用SourceLink，安全地址及新窗口rel沿用公开链接规范。卡片没有嵌套按钮或第二个跳转，若业务需要多动作/图片/产品图标/套餐价格，应选择对应专用规范，而非把整卡链接和多个交互嵌套。长词允许换行；焦点可见。

Sizes、Linked、LongText验证尺寸结构、语义链接、键盘及长文案。当前是基础文字卡片的独立实现，图片、图标、面板图文、禁用业务状态、源稿跨断点对照及人工无障碍仍需补齐。不能将此组件计为完整卡片家族验收通过，也不能用它替代尚未实现的规范楼层。
