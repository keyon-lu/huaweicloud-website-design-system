# v1产品推荐与通用图标文本卡片

## 产品推荐 `product-recommendations-v1`

来源PIX-00216:20250；独立入口`PortalProductV1Recommendations`。底部相关产品推荐使用，2～5列、16间距，同排等高，hover投影；64图标必填。手机768以下可显式hidden或compact；compact只保留40图标和标题，隐藏说明/重点文字/操作。数据由调用方提供，可接业务推荐结果，原型不模拟个性化算法。PC原始卡片16:22335为517×258，64图标、标题20/30、说明16/24；上下52，图标到标题24，说明间12。部分中小屏字号/列数仍需逐帧回归。

## 通用卡片 `generic-cards-v1`

来源PIX-00216:20251；独立入口`PortalProductV1GenericCards`。通用咨询/认证/案例等场景，2～5列、左/中对齐、图标可按扩展样式隐藏，iconHeight可选48/60/80；大屏80→64→60→H5 40，左上32→28→24、图文间28→24→20、标题20→16→14、说明16→14→12，底部40→36→32。支持重点文案分隔及最多两个黑/描边动作；按钮40→32，不使用#1476ff。无图标上下40。手机独立mobileItems，horizontal或stacked，不套用推荐卡片隐藏说明的规则。

两个入口都支持可选分类Tabs/副标题/更多，Tab使用v1容器；全局边距遵循用户24/14更新。全卡链接使用独立命名覆盖层，操作链接保持独立可交互，禁止嵌套a。按钮仅原生链接或禁用，不假冒业务交易。示例只用来源导出的CloudSite图标，正文可编辑。
