# 响应式与可访问性实现契约

全局容器/列数/页边距以[website-grid.md](website-grid.md)为准，覆盖原始PortalUI及旧样本容器值。组件断点仍独立：导航<=768，开放能力<=600，案例<840，Skills<=1280自然高度等。sm1024不等于所有组件一律换行或单列。

变更涉及栅格时检查375/376、768/769、1024/1025、1775/1776/1777，代表宽度1920/1905/1440/1026/954/565/390/320。这份清单是后续检查要求，不是用户已逐点验收记录。测根scrollWidth/clientWidth并考虑滚动条；卡片/方案/实践可局部横滚，不用根overflow:hidden掩盖问题。嵌套容器不得叠加百分比边距。

操作用button，跳转用a；保持focus-visible、原生禁用与跳过导航。手机菜单展开隔离背景并锁滚动，焦点包含；关闭恢复滚动和触发器焦点；Escape及回桌面可关闭。折叠图文方向键移动焦点，FAQ/details原生操作，复制失败选择输入提供手动回退。减少动效支持按组件实际实现检查，不能假定所有动效都已适配。

标题长英文、命令与文案裁切遵循[组件契约](component-contract.md)。复制成功勾号无可见另行提示，屏幕阅读状态仍保留。自动源码检查、实际键盘/触屏检查、人工整页验收与正式无障碍审计分开报告。当前用户验收范围见[台账](acceptance-ledger.md)，未指定完整视口清单或正式无障碍结果。
