# v1 Tab楼层容器

来源PIX-00212:53999，节点12:54078、表12:54331、规则12:54180。`PortalProductV1TabContainer`为TSX组合入口，内容为ReactNode，不按额外JSON楼层计数。主标题必选，副标题、链接可选；灰/白/透明与注册背景图片、左/居中和反白显式配置。Tab至少2个，数量无上限，点击当前项保持不刷新。源Tabs提供关联面板与键盘操作。

1920～1601/1600～1281/1280～769/768以下：标题36/32/28/18，副标题16/16/14/12，Tab18/16/14/12，换行Tab16/14/12/10；PC16字宽、H5九字宽；页签间80/64/52/28。PC超宽出现24/20/20滑块，手机以横滑承载。长文本不截断、不限制行数，换行测量后缩小2px；标题字号及手机阈值不继承2026版。

运行入口、键盘和类型接入不代表全量视觉验收。暗色主题不在本轮范围；反白只用于来源图片上文字。手机按来源表隐藏滑块并支持横滑，键盘聚焦所选页签时仍自动滚入视区。

无背景图片示例可通过生成器`--asset-ids-json <JSON数组文件>`显式打包空资源清单；若内容有图片则列出实际注册ID，未列出资源会在运行时明确报错。此参数仅支持--tsx-file，默认行为不变。

组合原语`PortalProductV1TabStrip`只渲染页签与面板，供来源允许标题隐藏的其他楼层复用；本楼层完整容器仍要求主标题，不改变其必填规则。
