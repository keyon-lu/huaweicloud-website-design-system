# 场景扩展与完成范围

当前可生成三条路线：公开产品页、已校准开发者首页、配置驱动官网组合页（解决方案/活动/资源/内容详情）。不同场景使用相同基础规范和共享组件，新路线不复制一份导航/页尾或修改既有产品页风格。

选择意图→对应路线/契约→真实数据与本地资产→共享组件组合→生成与检查→记录人工验收。若新需求仅为已有楼层顺序/内容变化，使用当前配置；出现新的状态、信息结构或业务流程时增加共享组件与schema，并保留来源和回归证据。控制台、后台管理、生产报名/支付、Pixso转换不在当前运行能力中。

原型运行能力与Creator正式转换/发布分开。当前内部设计材料、完整状态/Storybook/Pixso与参考质量证据仍不齐；不把配置扩展包装成正式全部组件转换。持续扩展是按后续用户请求推进，不创建无人值守任务或自动定时发布。

非标准页先按[楼层选型规则](floor-selection.md)拆解内容意图，再检索来源；楼层缺失时扩充其契约/组件/路由，不以现有模板数量限定可扩展页面，也不无依据造新皮肤。
