# 首版发布范围（2026-10-22）

用户已确认首版聚焦现有66条来源有限原型、19项已验收基础样本和本地检索；117条未实现来源列为后续扩展。本范围取代此前“全部183条/24家族完成才发布”的首版要求，不删除原始目录或伪造通过。

唯一机器清单是[first-release-scope.json](first-release-scope.json)。66条仅支持对应契约已经明确实现的分支；66不是66个完整家族或全部设计变体。新需求先检索该来源的generationKind、契约和参数校验；不支持的结构/皮肤/状态省略或说明受限，不自行设计。不将来源目录的117条延期项宣传为可生成。

基础范围为19项复验中的17个组件家族样本和2项基础视觉规范。图片查看器退出；服务表格合并fixed-table；select/rate缺正确来源暂停；日期选择暂缓；轮播/播放器只使用已有组合包装，不宣传独立全量基础家族。旧导出仅历史兼容。下载/菜单、复杂表格和未展示锚点适配分支不包含在已验收样本中，新增支持须另有真实设计与验收。完整图标/插图库不在首版承诺内，只使用已登记且语义匹配的原始资产。

八类检查仍保留：规格、适用状态、实现/入口、工程或交互、响应式长文案、源稿视觉和无障碍。检查的对象是采用契约的支持分支；不支持分支要有拒绝/省略路径，不通过写“不支持”删除实际已公开能力的验证。19项批准只覆盖记录中的具体样本，不能自动填满八类检查。117项只改为延期，不标记完成。

四核心分支仍为产品、已校准开发者首页、公共组合、本地检索。中文亮色；暗色、多语言、线上CMS/支付/账号/部署均不在范围。本地检索独立工程不声称生产API接入。

样式保护、来源优先级、按钮避免#1476FF及其他既有裁定不变。正式发布须当前快照评分达到既定门槛，工程、任务与产物证据分别闭环；文档评分不代替UI验收。

执行顺序：范围/门禁/文档对账→66条已支持分支的规则与证据核对→新需求整页生成回归→干净安装与封包→复评。未通过之前仍为draft。

## 已采用契约的执行规则

生成前从[first-release-contract-index.json](first-release-contract-index.json)定位来源→契约→导出→校验脚本；66条均有实际执行目标。`verify-release-contract-index.mjs`检查入口/规格指纹，改变后必须重新核对，不把重新计算哈希当验收。旧摘要存在空contract的5条已经与各自现存执行目标对齐，没有新增组件或外观。

视觉消费规则按[Token消费与状态政策](release-hardening.md)执行，颜色、padding/margin/gap、字号/行高/字重/字距、圆角采用consumer-token-map登记的语义变量或直接上游por变量。定义层允许来源原值，消费层禁止新常量；不得将无来源数值登记为变量后宣称合规。当前受管消费文件由verify-token-consumption逐项核对，新增消费文件必须加入清单，SVG路径/结构零值/已确认断点保留明确例外。302项基础样式并非统一覆盖旧产品/开发者数值的许可。

默认态从对应契约、样本和实际导出获取，禁止只读目录名称猜布局。各契约支持的布局/变体/参数以生成器输入校验为准；配置缺失、错误类型、未知结构或未登记资产保持原输出并报告字段；不把错误输入渲染成臆造占位样式。纯展示楼层没有内建异步loading/error，外部链接行为由目标站点负责；本地交互需保留default/hover/selected/disabled/focus的来源定义。真正异步的复制/本地检索遵循10秒超时、busy、防重复、保留输入、手动恢复等明确契约。

源稿未实现的变体不作为首版支持；这不豁免已经公开的支持参数。响应式、长文案、键盘/读屏和源稿视觉仍要有相应范围证据，不能用静态规范覆盖率冒充产物通过率。

## 阴影与层级：沿用实际消费者

不发明全局Elevation体系，沿用component-tokens.css/consumer-token-map.json及PortalUI的por语义变量。实际页面根层：跳过导航1100、弹窗1050、弹窗遮罩1040、页头1030、页内导航1020；这些来自portal-adapter.css及模板portalui-offline.css，后者por-modal-dialog使用por-modal-shadow和por-modal-radius。文档中的数字是来源定位，消费代码仍引用已有变量或来源库规则，不从文档复制硬编码。

SourceDesignAction的面板z-index=5和悬停底板-1只在触发器局部上下文使用，不得拿它与根级1030直接比较；导航移动面板位于页头上下文，继承现有1001局部层级。变更父元素transform、isolation、overflow或portal挂载点将改变遮挡关系，必须按受影响组合重验，不能只增大z-index。弹窗遮罩在正文之上、弹窗内容在遮罩之上；原生对话框/菜单沿用对应来源的挂载和焦点规则，不强塞新统一层级。背景图-1只用于原来源定位，不作为交互层。禁止对已有烘焙阴影重复叠加CSS投影。
