# 场景差异与证据边界

| 项目 | 当前处理 |
|---|---|
| PortalUI版本 | 3.0.17是用户选择的基础资料；产品样本3.0.18、开发者历史3.0.9分别记录，不推定同版本 |
| 公共框架 | 两场景共用PortalHeader/PortalWebsiteFooter实现，业务links/groups与variant分别配置；不再称为两个精简包装 |
| 容器栅格 | 用户2026-10-14统一裁定覆盖历史容器测量；组件内部布局保留作用范围 |
| 楼层 | 产品五类共享floor与GaussDB参考扩展；开发者实践/空间/Skills/开放能力；没有全站强制楼层顺序 |
| 内容与媒体 | 已接入Logo、产品/首页登记素材和GIF；华为字体未打包，视频为海报外链/手动切换 |
| 验收 | 当前开发者页面已人工通过；旧产品验收按原范围保留，公共框架变更不自动获批 |

Source DOM/计算样式、源码快照、实际浏览器轨迹和用户验收是不同证据。Pixso DSL、Storybook、正式无障碍及全站官方视觉认证仍未完成。最新规则与冲突见[当前规范](current-standards.md)，历史文档中的当时待验收状态以[台账](acceptance-ledger.md)判断。
