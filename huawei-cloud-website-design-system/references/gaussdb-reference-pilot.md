# GaussDB 首段参考校准

用户选定GaussDB作为首个精校样本，2026-10-12。覆盖导航框架、产品二级导航、白底居中首屏、官方产品图标和产品新动态三卡片。通过 `--variant gaussdb` 生成；完整产品页后续楼层尚未在此试点实现。

来源是官网实例的计算样式、截图、用户导航Logo和官方产品Logo目录。仅限此场景候选，不提升为全站规范。桌面首屏440px、手机350px，手机隐藏描述；产品动态的16px外间距、卡片布局/字号按测量映射。

顶级导航为简化直达链接，活动入口指向GaussDB开发者版；完整Mega Menu、更多导航、搜索/客服图标待做。部分产品导航和行动入口使用对应官方资源页回退；需要逐个确认目标，不等于业务购买接入。活动广告条暂未包含，比较几何时必须减去原站58px广告条，不能声称绝对位置全同。

本试点没有价格楼层、客户案例、认可与伙伴、完整页脚，也未完成字体或视觉正式认证。正式Creator阶段仍未通过。新导航Logo已实际接入离线生成组件，图像只由已登记包内Asset ID读取；不开放任意远程媒体。

GaussDB目录Logo与首屏展示图标是两份独立素材；本首屏使用现场CSS确认的GaussDB01.png，目录GaussDB.png保留作目录产品身份素材。部分页面的固定滚动条槽用于控制比较宽度，不是新的全站规范。
