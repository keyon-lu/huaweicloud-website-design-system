# 2026基础楼层框架

来源PIX-001 `0:1`，代码入口`PortalProduct2026FloorFrame`，接收children，可包明确已选的内容组件；这是组合基础片段，不新增虚构JSON楼层类型。spacing normal/none、align center/left、白/灰/透明背景，标题必填，结构化副标题可含黑色下划线链接。直接子选择器避免把内层组件标题覆盖。

标题36/54→32/48→28/42→839以下24/36→768以下18/28；顶底间距76/60/52/40/40，标题副标题间12/10/8/4，标题组至内容32/28/24/20。来源基础页H5标注768～375，与许多业务楼层599手机断点不同：本基础框架只对自己的标题适用768，不覆盖业务组件独立媒体断点。全局栅格继续按用户确认规则，内部字体断点独立。

源308标注28而实际24/42冲突保留，默认框架在1024仍取明确的28/42分支；不能把该冲突解释成按钮行高。当前未把此新框架强行覆写所有已实现业务楼层，其间距需按各自源例稿继续对齐。所有floor间连续背景合并间距与完整Tab组合视觉仍待验收。
