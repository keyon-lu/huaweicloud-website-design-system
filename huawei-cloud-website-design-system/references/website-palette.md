# 官网按钮与复选框颜色

2026-10-16用户澄清：**按钮场景避免使用 `#1476FF`；复选框允许使用该颜色。** 此前助手将限制扩大为全界面禁蓝，现予纠正。旧DEC-001不恢复为文字按钮颜色许可。

按钮范围包含原生button、button/submit/reset类型input、role=button、公共按钮组件，以及采用按钮类的链接。按钮自身及内部图标的默认、hover、pressed、focus、disabled、loading状态均应核查；十六进制大小写、RGB等值及透明变体适用同一规则。复选框选中/半选的蓝色使用独立组件语义，不绑定按钮色。

其他组件按各自来源规范处理，不把复选框许可自动推广成全局蓝色主题，也不把既有非按钮中性样式批量改回蓝色。website-palette.css中原有中性映射保留兼容；信息色、日期选中色与焦点的现有映射不表示这些场景被用户禁止使用蓝色。新增或改动按来源证据处理，有设计冲突提交用户裁定。

源码校验仅能识别静态按钮语义及其局部绑定值；CSS校验检查已登记消费样式的按钮选择器并解析变量。动态组件、宿主继承、状态覆盖及实际渲染仍需浏览器计算样式验证，不以字符串扫描替代完整视觉验收。原始来源文档与历史证据保留。
