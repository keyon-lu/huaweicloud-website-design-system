# 视频与直播（原地播放器）

来源PIX-00226:3807，D2C、原稿26:4577/4600及说明26:4179/4206/4211/4570/4573/4574/4625/4737/4821已核对。JSON `live-video-v1`，`PortalProductV1Live`，不使用弹窗视频卡片替代。

原地原生controls播放器、单击原生播放/暂停、双击请求全屏；有声音内容要求字幕元数据。可省略poster，此时使用浏览器视频首帧，失败提供重试，页面隐藏及卸载暂停。默认PC媒体宽1080/864/692/542（对应1600/1280/1024区间），16:9；内容侧栏占剩余宽且限制到同一行高，内容超长滚动、32/24内距。点击12×52侧边把手，隐藏右侧并把媒体扩为内容区2:1；无侧栏默认75%宽度居中。支持可编辑段落、加粗、黑色下划线文字链、配图及最多两个操作。支持无楼层标题/副标题。

本次为亮色本地播放器原型。手机暂用上下堆叠与手动展开的工程适配，原稿手机细节、完整子内容排版、白字背景图分支及真正流媒体服务未接入，不把本地播放器称为生产直播。原图26:4221单独导出作海报，不包含原稿播放器按钮截图。浏览器原生controls不保证跨浏览器像素一致，源视频基础组件完整视觉待验收。
