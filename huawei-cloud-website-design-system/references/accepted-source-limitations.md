# 用户已接受的原稿限制

2026-10-26用户明确选择“按原稿保留并记录未达标限制”，详见[原始裁定记录](owner-decisions-2026-10-26.json)。该裁定仅替代2026-10-22记录中`next-contrast`、`live-contrast`的“保持待定”；历史记录及旧测试结果保留。

| 对象 | 设计处理 | 合规结果 |
|---|---|---|
| [2026下一步](product-2026-next.md)，`next-step-2026` | 保留原稿文字与背景配色，不自行加遮罩或改色 | 已知对比度未达标，用户接受保留；不得声明WCAG AA通过 |
| [直播预告](product-v1-live-preview.md)，`live-preview-v1` | 保留原稿灰色文字及背景配色，不自行重绘 | 已知对比度未达标，用户接受保留；不得声明WCAG AA通过 |

这两项的设计处理决定已经闭合，不再重复要求用户裁定；它们仍是生成物需要披露的限制，不被记作无障碍通过。生成涉及这些楼层的页面时，在交付说明中列明对应限制，生成器的JSON结果也按配置的楼层或声明使用的组件附带`knownLimitations`。该信息属于交付元数据，不向网页添加说明条、弹窗或其他原稿没有的视觉元素。

此决定没有批准整个组件、其他配色或整页验收，也没有豁免读屏、触屏、软键盘、适配、特殊状态、全量原稿对照及其他正式发布检查。发布检查继续保留这些未完成项目。
