# 步骤流程楼层：合作伙伴页参考

## 来源与纠正

用户在2026-10-16指定[合作伙伴页](https://www.huaweicloud.com/partners/)倒数第二个内容楼层“立即开启合作”。真实组件为cnpm-pep-product-process-v2/2.4.31，选择器`.pep-product-process-v2 .process-container`。原始CSS及其SHA见[source记录](process-steps-source.json)和[原始CSS](source-assets/process-v2-2.4.31.css)。观察的是4步、中文、亮色；页面加载的基础主题为3.0.18，当前包保留3.0.17基础Token，二者不得混称同一版本。

2.4.0曾选用旧`.pro-process-steps-container`的100px六边形编号和居中排版。该样式虽存在于旧资料，但没有证明适用于本楼层；因此撤回其默认推荐，不把“CSS中存在”当作“当前样本规范已确认”。历史验收证据只属于旧实现，不能继承为新版视觉通过。

## 用途与选择

用于用户按先后顺序完成注册、认证、接入或学习的简短流程。桌面各步骤横排，金色数字、左对齐标题/说明、步骤间灰箭头、可选描边操作按钮。不是装饰优势卡片，不是完成进度条，也不是切换内容的步骤页签。标题没有目标时只作标题，不能输出无href的假链接；每个操作必须有真实href，不能把纯说明项做成整卡可点。

当前公开接口`PortalProcessSteps({items,label?})`：items为3或4项；item={title,description,href?,action?,icon?:1|2|3|4}。icon省略时按步骤顺序使用已登记的官方SVG。3步宽度有来源CSS依据并作工程验证；官网本轮观察的是4步，不冒称3步另有整页样本。5/6步、金色以外皮肤、可交互进度、无序场景都应先补对应参考和变体，不能从旧组件资产自动外推。

路由`website-composed.sections[].kind="process-steps"`及`website-product-floor.floors[].kind="process-steps"`。已有3–6步旧草稿API收紧为3–4步；5/6步明确拒绝并保留已有输出，不自动拆卡或造编号。

## 复用与验收

`ol/li`表达顺序，编号SVG及箭头为空alt装饰，读屏以有序列表和标题获得顺序；只有真实按钮链接参与Tab，焦点沿用全局规范。不复制源站的无href标题a、登录弹窗代码、跟踪参数或账号状态。

每次修改需检查：官方SVG及哈希、3/4项与非法步数、桌面四列和手机编号/文案/按钮对齐、无根级溢出、长文案、原生链接焦点与实际尺寸、按钮默认/hover/focus及#1476FF停用规则。源码、视口测量、视觉比对与用户验收分别记录；旧2.4.0截图不作为新实现通过依据。人工读屏/原生触摸/放大文字未执行时保留缺口。
