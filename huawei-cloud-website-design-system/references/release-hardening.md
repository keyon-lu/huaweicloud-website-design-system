# 源码基准发布整改

## Token消费

component-tokens.css为本地组件语义别名定义，consumer-token-map.json逐项记录消费文件、选择器、属性和保留值。值均来自原实现，不新增官方视觉裁定。颜色、padding/margin/gap、字体/行高/字重、圆角、阴影尺寸和层级以属性角色映射；上游--por-*继续直接消费。不是将任意新常量登记后自动批准：新增值仍按来源/用户确认/候选归类，消费文件改动必须重新做Token扫描和等价/差异审查。

原始PortalUI是来源Token/样式定义，保留版本；SVG图形坐标、动态列表列数、结构零值和已确认媒体查询断点是受控例外，不能用例外容许新颜色、组件间距或字号硬编码。现有自定义变量定义由registry列出。verify-token-consumption核对定义、使用、来源和审计过的消费文件哈希；verify-responsive-source在展开同一映射后继续检查原尺寸，不删除原断点/自然高度用例。原始样式中尚未归一的值不冒充新的全站设计Token。当前页头搜索和命令输入新增可见焦点声明是明确的可访问性修复，单独记录，不混入数值等价证明。

首版全部采用分支的来源/执行入口见[first-release-contract-index.json](first-release-contract-index.json)，层级及局部上下文关系见[first-release-scope.md](first-release-scope.md)。

## 全分支状态与焦点

新增/修改交互组件必须在规格中逐项处理default、hover、pressed/selected、disabled、loading、error、empty、focus；不适用必须说明纯展示/无异步等原因。默认结构/样式来自组件契约和PortalUI对应家族，不重造另一套皮肤。按钮hover/pressed/disabled沿用来源状态；链接hover需可见反馈，当前项用aria-current或aria-pressed。纯触屏不得依赖hover访问关键信息。状态优先级：disabled禁止激活；loading禁止同请求重复提交但允许取消/改条件；error保留输入并给恢复；focus-visible在错误和激活状态仍须可辨，不被背景/边框替代。不得无替代outline:none；检查聚焦控件自身和祖先裁切。

菜单Tab焦点包含、Escape关闭、关闭返回触发器；折叠媒体方向键仅移动焦点，Enter/Space选择；FAQ使用原生details；轮播手动操作、边界禁用；复制失败选中原命令并提示手动复制，不执行命令。来源默认/激活与禁用的具体视觉从原组件家族继承；缺少映射或与实现冲突时该组件状态不通过，不能靠此规则宣称全量实现。

本地检索查询和详情统一10秒超时，不自动重试；错误与空结果分开。取消或卸载移除计时器/监听，不显示取消为错误；新查询取消旧请求且忽略旧完成。保留查询条件，手动重试；loading通过status和aria-busy表达；相同请求禁用重复提交，不禁用所有条件修改。Input通过useId关联label，多个检索实例不复用固定ID。接口失败、非JSON、超时和取消有独立测试。

## 适配、文案与运行边界

横屏按实际可用宽度和组件断点重排，不按设备名锁方向；菜单/详情高度不能锁定屏幕绝对高度，软键盘出现时保留可滚动内容与可见聚焦控件。150%文字缩放允许标题和按钮组换行、长串断词、列表局部滚动；不得用根overflow:hidden掩盖内容。截断内容须有可访问的完整文本/详情路径，不只用鼠标Tooltip。GIF/复杂动效仍需要静态替代素材和减少动效实现验证，不能仅写规则判已完成。暗色映射仍未建模；不擅自制造品牌色，保持缺口计分。

生产UI文案需要统一资源/Key、参数插值和约40%扩展；静态来源文案和规范文档不等于i18n。资料快照日期不伪装实时更新；后续地区化使用Intl并指定locale/timeZone，价格必须含币种。Portal组件现以同文件portalCopy统一静态文案资源，检索UI以messages.ts统一文案Key，迁移保持原文；JSON业务内容与品牌专名不冒充界面控件文案。当前仅zh-CN资源，不声称其它语言翻译完成。检索数字通过Intl.NumberFormat且useGrouping=false保留原统计样式；资料日期用Asia/Shanghai日历日期和Intl.formatToParts保持YYYY-MM-DD，不将相对更新时间重新计算。原产品参考价格保留明确的来源/区域快照，不当作实时计价；新计价业务必须含币种并用Intl.NumberFormat，缺币种不能猜测。

本地验证预算候选：回环环境8文档、单进程、10并发、预热10次后100次查询，报告P50/P95与错误率；P95目标200ms只适用于此验证环境，不是线上SLA或实测结果。超时10秒、手动重试、只读接口、无共享写状态；进程重启整体加载带哈希索引，不热覆盖半份索引。输出工程只写空目录；并发命中同一路径必须保留已有文件并报错，不能使用覆盖开关隐式抢占。

公共接口废弃前至少保留一个次版本的兼容入口，迁移说明列出旧/新接口、影响分支和退出版本；未知历史接口不得按统一周期直接删除。公共样式修改使对应视觉证据待复核；旧验收绑定原产物，不随新版本继承。

## 发布判定

用户指定D盘中文主目录保留，英文分发根目录作为安装候选；不得为评分移动主包。静态评审分别声明实际对象，英文分发的命名符合不能抹去中文主包的命名偏差。

源码基准与Pixso转换是两条证据路径；本轮不伪造Pixso节点或把48个导出当成全量组件。正式Creator门禁继续要求组件/页面参考质量及实际交互证据；静态评分达标也不自动授权正式发布。运行并如实记录失败，未过门禁的分发仍为draft。
