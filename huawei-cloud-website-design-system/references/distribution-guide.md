# 候选包与版本使用

当前2.6.0-draft候选为可运行候选包，不是正式P8认证。三条页面路线的React/Babel/CSS/资产离线内嵌，运行需要Node.js，示例输出在包外。另有本地搜索独立工程模板，需要pnpm安装锁定依赖及构建。优先读取根SKILL.md；skills/SKILL.md仅内部路由。

每版保留runtime-manifest文件SHA-256，verify-standalone-package核对资源/编译；verify-contract-docs核对实际签名与维护链接；verify-p2-model核对分类台账；两个行为/响应源码脚本不替代浏览器检查。打包复制公共资源，不带.skill-creator材料/缓存、历史HTML或工作备份；在独立目录验证并至少生成一份默认产品和一份开发者页面。

旧兼容导出目前仍在；已有产品JSON的五种floor字段保持兼容。全局栅格/导航/页尾变更时重新检查受影响页面，不把旧HTML验收扩展到新生成结果。未来正式发版须补动态/参考质量、组件转换与评分门禁；不要把draft的成功编译当正式认证。

2.1.0新增website-composed与四类组合示例，旧两条路线及现有props不移除。48导出源计划见source-component-plan.json，正式转换未完成。

2.2.0新增独立本地搜索业务工作流、38文件模板、完整本地文档家族矩阵，以及用户确认的源码基准验收范围。分发排除node_modules/dist/storybook-static和原工程运行日志；模板复制后须重新验证。原页面生成路线和离线编译器限制均保留。

2.6.0-draft候选增加九份优先来源的规范检索、实际组件变体目录和内容目的选型提示。当前183个工程模板文件、73个公开函数、21个独立家族部分实现、11类生成楼层；完整24家族及优先设计采用门禁仍待完成。复制源包或生成页面成功不等于正式发布。分发须以runtime-manifest为文件清单，既有本地资料、缓存、证据备份和历史报告不打入运行包。

本批新增独立锚点导航、参数表、服务表、图片查看器及文档相邻页导航。图片与相邻页按精确来源页面片段追踪，楼层kind数量仍为10；未按17/21个部分实现宣称家族完整验收。
