# P2规范建模与边界契约

## 门禁与评分

P2出口要求相关1.3.3维度均有来源、候选、缺口或合理不适用说明；不是全部56项完整符合。创建台账保留56唯一ID与2个暂停考核项；部分符合不因有文件而升级完整符合。正式发布的分数、组件转换、Storybook、Pixso和动态证据仍须各自验证。P2通过不能替代P3–P8。

## 已建模的维度

颜色、间距、字号/行高/字重、圆角和层级沿用PortalUI语义与明确的场景覆盖；原始token定义与适配层原始常量分开。楼层12px、导航24px、页尾84/30px、复制壳24px不是同一个栅格槽宽。全局栅格24/8/4、1776归宽屏假设按website-grid维护。

状态默认/选择/展开/关闭/禁用/复制成功与失败均以component-contract为准。hover来自源CSS，触屏不依赖hover作为唯一入口。焦点可见是实现要求；搜索input的outline0通过父容器focus-within可见环补偿，仍需实际焦点检查。复制现已提供busy防重复、10秒超时和手动回退；平台剪贴板操作无法取消，不声称可中止底层写入。详见发布整改契约；其它组件状态仍逐项验证。静态页面无数据时省略可选楼层，搜索无结果有提示；不宣称完整权限异常体系。

手机/平板/桌面采用全局宽度与组件局部断点。横屏使用当前宽高/内容滚动作为候选，150%缩放需实际浏览器验证；不能以公式覆盖充当旋转或缩放测试。减少动效仅按具体组件现有分支检查，不能宣称所有平滑搜索或GIF已处理。

语义button/a/details与ARIA、焦点包含/恢复和背景inert是本包实现，不是全站无障碍认证。AI页面展示历史业务资料/图像、命令和外链，不生成推理结果、不执行命令、不管理智能体；全部支持路由及所有共享/参考组件均无AI流式、信任或错误状态。因此AI运行输出五项在当前范围不适用；以后引入AI运行界面必须重判。静态媒体中的AI界面不是运行中的代理输出。

中文内容保留真实来源，约40%长度扩展检查换行/裁切，不编造字符上限。国际化资源、RTL和多地区时间/货币为未支持/缺口；历史更新时间文字不转为实时。价格包装现有en-US格式不能冒充完整Intl层。

生成器检查部分必需字段、floor kind/id/非空列表与Asset ID；href业务真实性、案例数组长度、任意TSX props和重复挂载隔离仍由调用者负责。输出保留原文件/覆盖明确、包哈希/接口签名验证；客户端单文件不依赖联网库，外链不计作运行依赖。无后端P95/SLA、生产监控或任意JavaScript沙箱承诺。

## 缺口处理

字体与内部设计资料仍由用户延期；现有媒体已接入到样本范围，不能保持“完全无媒体”的旧缺口，也不能升级成完整品牌库。中文工作目录按用户指定保留，英文候选分发目录独立。阶段结构和转换能力是两回事；component registry来源于实际46导出接口，不是Pixso变体转换完成证明。

正式评分/发布前还需Token消费治理、正式组件状态/动态追踪、原站多视口参考、国际化及适用性复核。全部缺口须在创建台账与readiness中保留；新页面样本人工复核不自动变成P2全维度完整符合。
