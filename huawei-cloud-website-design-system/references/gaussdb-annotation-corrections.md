# GaussDB 九条标注修订

版本2.0.4-draft，2026-10-12。用户决定 SRC-125；分辨率规则提取 SRC-126。这些规则仅用于已选GaussDB组件，不成为全站Token。

|标注|实施方式|证据与范围|
|---|---|---|
|1|高亮是默认卡片背后的独立背景层；1920时上40、左右下2；使用官网蓝色渐变图片填充，标题在露出的上沿|1920尺寸USER_CONFIRMED；其他宽度参考同来源promotion组件，仍属INFERRED_CANDIDATE|
|2|楼层链接规则排除.por-btn，恢复PortalButton原有反色文字及hover/disabled样式|实现修复，不使用宿主CSS重写按钮颜色|
|3|普通角标right:0，左右padding16，radius为0/R/0/R|用户确认；R跟随当前卡片圆角|
|4|优势小图标48/40/32px，间隔32/24/20px|对应GaussDB优势模块CSS；599以下图标仍32|
|5|客户Logo取消180px上限和20px内边距，图片100%宽高+contain；标签高度110/88/72/60|对应GaussDB客户模块CSS；contain保留图片内部留白，不拉伸商标|

分辨率表按CSS视口宽度，不能把设备物理分辨率直接当CSS宽度。>1600用第一档，<=1600、<=1280、<=1024依次覆盖。推荐背板上沿40/32/28/24；<=599使用32并留足行间距，这个推广来自类似promotion组件，未取得当前GaussDB推荐卡的逐宽度运行证明。角标16px横内边距是用户确认的1920值，当前其它档沿用候选；未宣称用户确认所有档。

视频官方图标的尺寸16/12/10px，<=840为9px，<=599为10.67px。元信息固定在卡片左下角，不因标题换行而上下移动。视频链接仍进入官方资源页，本次只修正图标视觉，不宣称已实现播放弹层。

验证边界：本轮完成编译、包完整性、离线生成与来源/Asset ID检查。新增修订的浏览器运行截图、交互颜色、背板实际盒模型仍待验证。先前file URL安全限制继续遵守，没有通过其它协议/浏览器绕过。需要对照图时由用户在已打开草稿中刷新后标注。

第二轮标注 SRC-129：时长在左、播放图标在右，替代先前的左右顺序。推荐背板保持原来的40/2px等盒模型；PNG有预制圆角，显示时图片四边各超出8%，避免预制圆角与容器圆角叠加，容器overflow:hidden统一裁出圆角。PNG原文件不修改。本轮编译和生成检查不等于已完成浏览器截图确认。

响应式组合更新以[组件响应式修订](gaussdb-responsive-corrections.md)为准，旧的768全改单列规则不再适用。
